Module: Front-End Architecture

The following table details the technical implementation requirements for the Home Screen wireframe (WF-01). Data binding and reactive states must strictly adhere to these API contracts.

ID Requirement Specification
[1] RF-01 Header Branch selector (`GET /sucursales`), status 'OPEN'.
[2] RF-02 Search Debounce (300ms), Camera trigger for barcode (`GET /productos?q=`).
[3] RF-03 Promo Dynamic slider (`GET /promociones`).
[4] RF-04 Taxonomy Category chips (`GET /categorias`) with SQLite local filter.
[5] RF-05 Grid Pagination, reactive sum to CarritoService.
[6] RF-06 Totals Reactive badge, item count, subtotal.
[7] RF-07 Nav Angular router to `/catalogo`, `/mis-pedidos`, etc.
